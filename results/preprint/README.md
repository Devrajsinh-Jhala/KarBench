# Preprint tables

The CSV files mirror the aggregate tables in the [supplement](../../paper/supplement.md). Consult it for denominators, completion rules and data provenance. These tables contain aggregate values.

[Table C5](table_c5_deadline.csv) reports the retrospective 240-second filter on the single-request modes. The "_240" columns require both an in-protocol completion and logged end-to-end latency at or below 240 seconds. See [revision 1.1](../../paper/revision-1.1.md) for interpretation.

[The USD cost table](table_7.csv) uses saved precision. The Total row is computed before rounding to cents.
