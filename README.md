# KarBench

**Can language models calculate and cite Indian income tax?**

KarBench evaluates whether language models can compute personal income tax under both regimes, select the lower-tax regime, and cite the law applicable to the income period. It uses 100 synthetic salaried profiles, each paired across FY 2024–25, FY 2025–26, and TY 2026–27.

The study compares closed-book answering, a supplied rule card, and an agent with access to dated rules and a calculator. The main experiment contains 5,400 attempts across six model configurations. It reports tax accuracy, statutory citation accuracy, and completion separately.

The results are diagnostic. The engine provides reference answers for the synthetic cases, and the case-level outcomes of the independent 30-case review are pending documentation.
